## 검증 자료를 만드는 데서 끝나지 않습니다

marketvalley는 첫 시장 반응을 확인하려는 예비창업가와 1인 사업자를 위한 시장검증 워크플로입니다.
문제 배경과 제안할 솔루션을 입력하면 하나의 검증 가설을 기준으로 필요한 채널을 함께 만들고,
공개하고, 실제 관심 신호를 다시 모읍니다.

### 1. 아이디어를 한 번 설명합니다

누구의 어떤 문제를 해결하려는지, 어떤 솔루션을 제안할지 두 단계로 입력합니다. 이 내용은 랜딩과
카드뉴스, 광고가 서로 다른 약속을 하지 않도록 모든 결과물의 공통 기준이 됩니다.

### 2. 한 가설에서 모든 검증 채널이 나옵니다

- 바로 공유할 수 있는 공개 랜딩페이지
- 같은 메시지로 이어지는 Instagram 카드뉴스 5장과 다운로드용 ZIP
- 후킹 문구, 캡션, CTA와 Meta 광고 소재
- 확인하려는 신호와 반증 조건

### 3. 공개 뒤의 반응을 한곳에 모읍니다

광고가 시작되면 Meta의 실제 노출·클릭, 공개 랜딩의 고유 방문, 이름·이메일 제공에 동의한
사전예약을 수집합니다. 생성과 수집은 브라우저 탭에 묶여 있지 않아 사용자가 창을 닫아도 저장된
단계에서 계속되며, 일시적인 외부 API 실패 뒤에도 처음부터 다시 만들지 않습니다.

### 4. 마지막 판단은 사람이 합니다

결과 화면은 실제로 저장된 관찰값과 처음 세운 기준을 함께 보여 줍니다. marketvalley가 시장성을
보장하거나 성공 여부를 대신 판정하지 않습니다. 사용자가 **계속 검증·메시지 수정·보류** 중 다음
행동을 고르고 고객과 대화합니다.

## 실제 값과 예시 값을 섞지 않습니다

운영 리포트에는 저장된 Meta Insights, 고유 방문과 동의 기반 예약만 표시합니다. 발표용 예시는
별도 경로에서 예시임을 밝히며 운영 프로젝트와 섞이지 않습니다. 현재 광고 자동화는 팀이 승인한
광고계정, 고정된 총예산과 종료 시각이 일치하는 범위에서만 동작하고, 자동 예산 증액이나 종료 광고
재시작은 하지 않습니다.
